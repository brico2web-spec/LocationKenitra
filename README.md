# Kraylia

## Run the site and admin panel

This is a static website. Open `index.html` to view the site and `admin.html` to manage it. No Node.js installation or email setup is required.

The admin page has a demo login gate. Because GitHub Pages serves static files, the credentials are included in the public page code and the gate is not real security. Do not use it to protect private or sensitive data; use server-side authentication for a secure admin panel.

Site settings and bookings are saved in the current browser's local storage and are not synchronized across browsers or devices.
